# Olist E-Commerce Analytics

Analysis of the Olist Brazilian e-commerce dataset (orders placed between 2016 and 2018) covering revenue growth, customer retention, and delivery performance. Data preparation and analysis are done in Databricks; reporting is built in Power BI.

## Data

Source: [Brazilian E-Commerce Public Dataset by Olist (Kaggle)](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

## Tools

Databricks SQL · Power BI · GitHub
